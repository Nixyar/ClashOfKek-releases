# ClashOfKek: релизы

Здесь лежат готовые сборки программы ClashOfKek для Windows. Исходный код в этом репозитории не хранится.

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте файл `ClashOfKek-v…-Windows-Portable-….zip` (около 115 МБ).
2. Распакуйте его в короткую папку, например `C:\ClashOfKek` (не в `Program Files`).
3. Запустите `ClashOfKek.exe`. Если Windows пишет «защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
4. В BlueStacks: разрешение экрана 960×540, включён ADB, язык игры English. Подробности в файле `INSTALL.md` внутри архива.

## Обновления

Программа сама проверяет эту страницу и предлагает обновиться: внизу окна кнопка «Проверить обновления», а при выходе новой версии вверху появляется плашка. Скачивать архив заново не нужно, если плашка не пишет «нужен полный архив».

Автоматизация игры нарушает правила Supercell и может привести к блокировке аккаунта. Используйте на свой риск.
